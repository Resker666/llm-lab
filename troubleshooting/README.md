# Troubleshooting

A collection of LLM and AI engineering problems that I have actually encountered.

## Recommended Format

### Symptom

What happened? Include the exact error message when useful.

### Environment

- OS
- hardware
- model
- runtime / framework version

### Investigation

Commands, logs and hypotheses used during debugging.

### Root Cause

The confirmed cause, if known.

### Fix

The minimal working fix.

### Verification

How the fix was verified.

### Lessons

Reusable knowledge for future incidents.
